# 贡献

## Report Bugs

混淆工具和Android系统发布地如此之快 - 导致bug层出不穷。当你认为你发现了一个bug，你可以这样做：

1. 搜索已有的issue，如果找到相同的，请评论你掌握的任何额外信息
2. 创建一个新issue，但是请遵从issue的模板

遵循issue模板很关键。维护者时间有限，如果一个issue没有正确的遵循模板，它将会被关闭

## 改进文档

任何大型项目都需要一个良好的文档，Apktool也不例外。文档保留在Apktool同一仓库的[docs](https://github.com/iBotPeaches/Apktool/tree/docs)分支，欢迎提交PR来丰富这个文档

当更新文档时，请遵循已有的格式。文档上会运行一个Lint检查，以确保遵循了正确的格式

为了在本地运行Lint检查，确保node依赖正确安装了，运行以下命令：

```
npm install
```

运行以下命令进行Lint检查

```
npm run lint
```

运行以下命令修复Lint检查发现的主要问题

```
npm run lint:fix
```

## 回复issues

另一种违法的帮助Apktool项目的方式是分类或者回复issues，这是开始参与项目并帮助其他用户的好方法。

## 修复bug

前面提到过，Apktool是一个开源项目，并且接收PR。如果你修复了一个bug，请提交[PR](https://github.com/iBotPeaches/Apktool/pulls)

## 建议一项功能

尽管Apktool的主要关注点在修复bug，但是也一直会有新的功能加入。如果又有任何建议，请在[Ideas](https://github.com/iBotPeaches/Apktool/discussions/categories/ideas)中创建讨论
